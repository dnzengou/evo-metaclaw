Constitutional Constraints

The Four Axes

Every proposed child mutation is evaluated deterministically across four orthogonal invariants before it is allowed to run.

B

Budget

Resource & Cost Envelope
cost & hours ≤ cap
Rule

Cost and hours must not jump.

Why

Prevents "improvement" that is secretly a resource grab.

Ci

Circuit

Recursion Depth Breaker
depth ≤ 2
Rule

Self-edit recursion depth ≤ 2.

Why

Caps self-modification depth (matches EvoForge max_depth=2).

E

Evolution

Fitness Floor Guard
fitness ≥ 0.8 × parent
Rule

Child fitness ≥ 0.8 × parent.

Why

Blocks regressions dressed as exploration.

Bl

Blacklist

Non-Negotiable Preconditions
clauses intact
Rule

Airgap, kill-switch, ownership, rate-limit… clauses cannot be deleted.

Why

The constitutional layer — not trade-offs, preconditions.

⚡ Fail one axis, the child dies.

Rejections carry their failing axes, so attempted escapes are themselves auditable data. Distinct from evo-skillopt's held-out Q-gate:

evo-skillopt Q-gate
"Is the child better?"
evo-metaclaw Gate
"Is the child allowed to exist?"
The Learning Half • Signal Organ

Signal Pipeline & Boundary Discipline

Conversation capture turns production interactions into append-only SQLite (WAL) events, distilled at session end into hypothesis drafts for gated training.

STAGE 1 • YOU ARE HERE SQLite WAL

evo-metaclaw

claw + capture + summarize
Records production signals and distills candidate SKILL.md drafts stamped "must pass held-out gate before use".

STAGE 2 • TRAINING Q-Gate

evo-skillopt

train + held-out gate + rollback
Evaluates distilled hypotheses against held-out benchmarks, promoting only verified improvements.

STAGE 3 • RUNTIME Genome Pack

EvoForge

install + idle-window mutation
Installs promoted skills as genome packs and dispatches scored champions on live tasks.

Boundary Discipline
  • • The claw governs constraints; it trains, versions, and promotes nothing (stays in evo-skillopt) and deploys nothing (stays in EvoForge).
  • • Sessions under 3 signals produce no draft (anecdote ≠ pattern).
  • • User feedback is the only quality signal; capture classifies mechanics only.
Zero Dependencies • Python Stdlib-Only

Quickstart CLI & SDK

Run the 16-test stdlib suite, gate candidate mutations, or capture and emit session signals.

# 1. Install and run the stdlib-only test suite
$ pip install -e ".[dev]" && python -m pytest     # 16 tests, stdlib-only

# 2. Gate a mutation directly from the CLI
$ evo-metaclaw claw parent.md child.md --parent-fitness 0.8 --child-fitness 0.85

# 3. Capture production session signals (requires ≥ 3 signals to draft)
$ evo-metaclaw capture demo1 task_failure "RuntimeError: timeout" --agent sales-bot
$ evo-metaclaw capture demo1 user_feedback "too verbose" --score -0.8
$ evo-metaclaw capture demo1 emerging_need "needs PDF export"

# 4. Distill candidate SKILL.md and emit to evo-skillopt worker
$ evo-metaclaw summarize demo1                     # → candidate SKILL.md
$ evo-metaclaw emit demo1 sales-bot --worker http://localhost:9000 --token $WORKER_TOKEN
from metaclaw import Mutation, gate

v = gate(Mutation(
    parent_md=open("skill_v1.md").read(),
    child_md=open("skill_v2.md").read(),
    parent_fitness=0.80,
    child_fitness=0.848,
    depth=3
))

print(v)   # REJECTED (Ci, Bl) — the +6% fitness is irrelevant

Governance & Signal

Honest Limits

Engineering transparency on what the claw guarantees—and what remains the responsibility of your deployment topology.

01 • Textual Tripwire vs. Semantic Proof

The claw's Bl axis is textual: a clause deleted and meaningfully preserved in other words passes. Treat it as a tripwire, not a proof.

02 • Mutation Path Wiring

"Makes the edit illegal" holds where the gate is wired into the mutation path. In a given deployment, verify the wiring before trusting the claim.
